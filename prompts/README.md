# Design Challenge Prompts

This folder contains design challenge prompts for the Design Challenge Coach app.

## How to Use

1. **Create a new prompt file** - Copy `template.md` and customize it with your design challenge
2. **Paste into the app** - Copy the entire prompt content and paste it into the "Design Prompt" field in the app UI
3. **Start practicing** - The AI coach will focus on the specific challenge, constraints, and success criteria you define

## File Format

Each prompt file should contain:
- **Challenge Overview** - The main design problem
- **Constraints** - Time, scope, platform, or other limitations
- **Target Users** - Who you're designing for
- **Success Criteria** - What a good solution looks like
- **Context** - Additional background information

## Example Prompts

- `airbnb-host-training.md` - Design a training system for Airbnb hosts
- `template.md` - Blank template for creating new prompts

## Tips

- Keep prompts focused and realistic (achievable in 60 minutes)
- Include specific constraints to make the challenge more realistic
- Define success metrics the coach can reference during feedback
- Include user personas or segments when relevant
